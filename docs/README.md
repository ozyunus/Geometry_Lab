# PatternLab — MVP Build Pack v1.0

**Product:** bilingual (Turkish + English), globally relevant, hands-on geometry and geometric pattern studio for curious learners, primarily school-age but not limited by grade. **Not** a curriculum, tutoring, exam-prep or religion-teaching product.

## Start here
1. Open `STUDIO_MASTER_PROMPT.md` and paste it into Google AI Studio Build mode.
2. Attach this ZIP or, if ZIP ingestion is unsupported, upload the files and `design/` references separately.
3. Ask Studio to implement the MVP, run it, fix errors and show a working preview.
4. Validate against `QA_ACCEPTANCE.md`. Do not treat screenshots or static mockups as a finished MVP.

## Files
- `PRODUCT_SPEC.md`: vision, audiences, navigation, scope and flows
- `LEARNING_CONTENT.md`: hands-on pedagogy, lessons, explanations, cultural context
- `GEOMETRY_ENGINE.md`: geometric object model and correctness rules
- `I18N_CONTENT.md`: bilingual architecture and initial UI copy
- `TECH_ARCHITECTURE.md`: implementation recommendations, storage and privacy
- `QA_ACCEPTANCE.md`: test scenarios and done criteria
- `STUDIO_MASTER_PROMPT.md`: executable brief for Google AI Studio
- `design/`: screenshots, design tokens, responsive UI and asset instructions

## Source of truth
Functional requirements in markdown override visual mockup details. Mockups are **visual references only**: do not reproduce sample profile avatars, login or accounts. The product is global; Islamic geometric art is one featured tradition, not the exclusive scope. No claim that every motif has a uniquely Turkish or Islamic origin.
