# Design system — PatternLab

## Identity
Global, inclusive, art-meets-math. Contemporary museum workshop rather than classroom worksheet. Brand: PatternLab (untranslated); tagline localized. Logo can be original eightfold rosette symbol, not a copy of a historic emblem.

## Palette
Background `#F8F5EE`; Surface `#FFFDF8`; Text `#14313F`; Teal primary `#087D86`; Teal dark `#08646C`; Amber `#D89A43`; Pale teal `#DCEDED`; Border `#E8E5DD`; muted text `#60757C`. Maintain WCAG contrast. Use amber sparingly for geometry points and hints.

## Typography and layout
Clean sans for functional UI (system or open-source); optional elegant serif for hero headlines. 8px spacing scale; radius 12–20px; subtle borders/shadows; spacious canvas. Desktop >=1024: tools / canvas / contextual steps. Tablet 640–1023: top steps, canvas, horizontal tools. Phone <640: compact header, canvas, tools, collapsible explanations; never shrink canvas to decorative thumbnail.

## Components
Global nav with TR/EN switch; PathCard; LessonStep; GeometryCanvas; ToolButton; LayerToggle; ExplainTabs (`Do It`, `Why It Works`, `Math Details`); CultureCard; PatternDecoder; ExportMenu; UndoRedoControls; LocalSaveNotice.

## Mockup interpretation
`reference_global_responsive.png` is the primary global direction. `reference_early_trio.png` is an earlier responsive drawing-workspace reference. Both are concept visuals, not production-ready screen assets; recreate UI as real components. Ignore mockup avatars or login icons because MVP has no accounts.

## Cultural imagery
Prefer self-authored geometric vector diagrams. Historic buildings/artwork: only use verified openly licensed images with source attribution; otherwise use neutral illustrative patterns and clearly label `Inspired by` / `Esinlenilmiştir`. Avoid reducing all Islamic geometric traditions to one country or era.
